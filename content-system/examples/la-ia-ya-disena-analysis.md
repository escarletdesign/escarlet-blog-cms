# Caso real: la IA ya diseña bien

El slug solicitado no está en las bases locales que acompañan este checkout, así que no se inventa una lectura de sus imágenes actuales. El archivo JSON deja registrada esa ausencia y separa los riesgos inferidos de los hallazgos comprobados.

La ruta preparada usa `metafora-visual-conceptual`: una tensión física, sin texto y con espacio negativo. El carrusel usa el template `editorial`, cuatro slides y texto montado por renderer. Cuando el post esté disponible en el CMS, el script de regeneración podrá conservar, reutilizar o reemplazar cada asset de forma selectiva.
