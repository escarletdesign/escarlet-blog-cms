# Estilo visual canónico de Escarlet

El sistema web usa azul principal `#47A4E7`, teal `#12B8D6`, verde suave `#62B38A`, crema claro `#F3E7D0`, amarillo oro `#E8B73A`, carbón `#1E1E1E`, gris `#6D6D6D` y blanco `#FFFFFF` cuando sea necesario.

La tipografía del sistema es Montserrat, con Arial como fallback. El degradado teal `#12B8D6` a dorado `#E8B73A` está permitido en héroes y llamadas a la acción del sitio web. No se usa como fondo global ni como sustituto de la paleta de interfaz.

El fondo obligatorio de las imágenes editoriales es `fondo-escarlet.jpg`. Conserva formas orgánicas estratificadas tipo montañas y el flujo cromático teal a la izquierda, verde suave en el centro y oro a la derecha. La autoridad visual principal es `05-tablero-visual.png`: define iluminación, composición editorial, anonimato de las personas y tono emocional.

La selección de referencias es determinista. El cliente no puede escoger ni sustituir referencias. Para trabajo, diseño, colaboración o escenas humanas se usa `reference-blog-example.png`; para tensión, duda o introspección se usa `reference-visual-style-01.png`; para escenas positivas, luminosas, inspiradoras o de crecimiento se usa `reference-visual-style-02.png`. Una petición genérica usa la ruta `positive_or_inspirational`.

Todas las imágenes se generan en 3:2, con sujeto en el tercio derecho y al menos un 25% de espacio negativo. Las personas son anónimas o parciales. No se permiten texto, letras, números, logos, marcas de agua, stock corporativo ni sustituciones.
