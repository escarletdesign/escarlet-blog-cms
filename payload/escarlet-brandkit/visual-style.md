# Estilo visual

Usa `assets/style-board.png` como tablero maestro y `assets/fondo-escarlet.png` como fondo de autoridad visual. El fondo conserva la textura orgánica de montañas y el flujo turquesa, verde y oro. Si se solicita a Silvia, usa `assets/character-silvia.webp` o el tablero de personajes sin inventar rasgos nuevos.
