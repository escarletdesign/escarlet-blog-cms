    Alta de un sitio nuevo
    
                
    Paso 1 de 3. Datos básicos del proyecto.
    
              
    
              
            
    

            
    
              
              
              
            
    

            
    
              
    
                Qué es el handle
                
    Es el id corto del site dentro del CMS. Usa kebab-case. Ejemplos. mares24, umbral, elektia.
    
              
    
              
    
                
    
                  
                  
                
    
                
    
                  
                  
                
    
              
    
              
              
              
    La URL canónica de los posts será dominio/blog/slug. Cópiala de la web en producción.
    
              
              
              
    Separados por coma. Si lo dejas vacío usamos «Equipo».
    
              
    
                
              
    
            
    

            
    
              
    
                Dónde sacar estos datos
                
      
                  
    1. Entra en Coolify y abre la app del frontend (la web pública del cliente). Es distinta de la app del CMS.
      2. 
                  
    2. Busca Webhooks o Deploy Webhook. Elige el de producción con auth required.
      3. 
                  
    3. Copia la URL. Suele verse así. https://coolify…/api/v1/deploy?uuid=…. Si trae force=false, el CMS lo quita. Al publicar o al interruptor, el CMS llama con force=true para que Docker no recicle el dist.
      4. 
                  
    4. En Coolify → Keys & Tokens (o Keys), crea o copia un token API con permiso Deploy.
      5. 
                
    
                
    Puedes saltarte este paso y pegar webhook y token más tarde en Configuración del sitio.
    
              
    
              
              
              
              
              
              
    
                
                
    
                  
    
                    
                      
                    
                    
    Suelta el ZIP del kit aquí
    
                    
    Opcional · solo .zip · máx. 40 MB
    
                    Elegir ZIP

                Al crear el sitio
                
    El CMS guarda el handle, el brand kit vacío para que lo rellenes, y el webhook si lo pegaste. Después conectarás el frontend con sync y packs.
    
              
    
              
    
              
    
                
                
              
    
              
    
                
    Sitio listo
    
                
    Sigue estos pasos en orden.
    
                
      
                  
    1. Abre Kit de marca y completa voz, estilo, keywords y AGENT.md. Sube 2 a 4 fotos de referencia.
      2. 
                  
    2. En el repo del frontend, pide al agente. «Integra el blog CMS con este handle» (skill escarlet-blog-integrate).
      3. 
                  
    3. En Coolify (app del frontend) pon las variables BLOG_CMS_URL, BLOG_CMS_SITE y BLOG_SITE_URL.
      4. 
                  
    4. Si aún falta el webhook, pégalo abajo en Configuración y pulsa Probar webhook.
      5. 
                  
    5. Publica un post de prueba y abre /blog/{slug} y /admin/blog-packs/{slug}.
      6.
